# Laboratory Activity 1 - Welcome to the Cloud

## Mission Overview
In this activity, I was onboarded as a Junior Cloud Infrastructure Engineer Trainee.
I learned how to use a Linux environment, check system information, and organize files.
I also created a GitHub portfolio to store my work for the rest of the semester.

## Objectives
- Access a Linux environment using KillerCoda.
- Explore basic Linux commands.
- Gather system information.
- Create folders and files.
- Build a GitHub repository.
- Write documentation using Markdown.

## Activities Performed
1. Created a new user account with sudo access.
2. Checked my Linux distribution, kernel version, CPU, memory, and disk space.
3. Created folders (Documents, Notes, Reports, Screenshots) and an about-me.md file.
4. Created a public GitHub repository named CCM101-rpaneda.
5. Organized the repository with the required files and folders.
6. Took screenshots as proof of each step.

## Linux Commands Used
whoami, pwd, hostname, cat, uname, lscpu, free, df, mkdir, touch, nano, cp, git clone, git add, git commit, git push

## Skills Learned
I learned how to use basic Linux commands to explore a system.
I also learned how to organize files and create documentation using Markdown.
I practiced using Git and GitHub to manage a project.
