# Reflection

This activity helped me get comfortable with the Linux terminal.
At first, some commands did not work the way I expected, especially with copy-pasting.
I learned to type commands one at a time to avoid errors.

I also learned how important documentation is in cloud computing.
Recording system information and writing clear README files makes work easier to understand later.

Setting up GitHub authentication was the hardest part.
I learned that GitHub requires a personal access token instead of a password for security.

Overall, this activity gave me a good foundation for the rest of the course.
