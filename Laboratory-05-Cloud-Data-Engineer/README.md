# Laboratory 05: Cloud Data Engineer

## Mission Overview
In this laboratory activity, I served as a Cloud Data Engineer at CloudNova Technologies[cite: 1]. The goal was to deploy an open-source, S3-compatible Object Storage server using MinIO on Docker, expose its interface via port forwarding, configure an object storage bucket named `client-photos`, and test file uploads to prove proof-of-concept functionality for a client application[cite: 1].

---

## Objectives
* Differentiate between Block, File, and Object Storage mechanisms[cite: 1].
* Deploy an S3-compatible Object Storage server (MinIO) using Docker[cite: 1].
* Configure port mapping and access cloud management interfaces[cite: 1].
* Create storage buckets and manage file uploads[cite: 1].
* Document technical architecture and maintain a GitHub Cloud Computing Portfolio[cite: 1].

* **Container Engine:** Docker[cite: 1]
* **Object Storage:** MinIO (S3-compatible)[cite: 1]
